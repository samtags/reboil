# Security Policy

## Supported versions

Security fixes are applied to `main` and the latest published release line. Older release lines are not guaranteed to
receive security updates while Reboil is pre-1.0.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's **Security** tab and choose **Report a vulnerability** to send a private report. Include:

- The affected Reboil version or commit.
- The affected platform and configuration.
- Reproduction steps or a proof of concept.
- The potential impact.
- Any suggested mitigation, if known.

Maintainers will handle reports confidentially, investigate on a best-effort basis, and coordinate disclosure and
credit with the reporter. Please allow time for a fix to be prepared and released before publishing details.

If private vulnerability reporting is unavailable, contact a maintainer privately using the contact information on
their GitHub profile.
