# Reboil Support

Use the channel that best matches what you need:

- **Questions and troubleshooting:** start a GitHub Discussion. Include the Reboil version, platform, relevant code,
  and what you already tried.
- **Reproducible bugs:** open a bug report with a minimal reproduction and environment details.
- **Feature ideas:** open a feature request describing the problem before proposing an API.
- **Security vulnerabilities:** use GitHub private vulnerability reporting as described in [SECURITY.md](./SECURITY.md).

Public issues are for actionable bugs and scoped feature work. They are not a private support channel or a place to
disclose sensitive information.
