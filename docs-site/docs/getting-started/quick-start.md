# Quick start

After installation and config registration, use a small counter to see the core Reboil workflow: define state, subscribe to a path, and update it through the store.

## Define the application state

Keep the initial state in `src/state.ts`:

```ts title="src/state.ts"
export const initialState = {
  count: 1,
};
```

Register the state. This is automatically generated by the `npx reboil init`

```ts title="reboil.config.ts"
import { createStore, defineConfig } from "reboil";
import { initialState } from "./src/state";

createStore(initialState);

export default defineConfig({
  stateFile: "./src/state.ts",
});
```

## Subscribe to state changes

Import the config before the package bindings, then use `useStore` in a component. The hook subscribes the component to the selected `count` path and re-renders when it changes:

```tsx title="src/Counter.tsx"
import { useStore } from "reboil/react";

export function Counter() {
  const count = useStore("count");

  return <p>Count: {count}</p>;
}
```

## Update the state

Use the configured package store to update the same path. The updater receives the current value and returns the next one:

```tsx title="src/IncrementButton.tsx"
import { store } from "reboil";

export function IncrementButton() {
  return (
    <button
      type="button"
      onClick={() => store.set("count", (value) => value + 1)}
    >
      Count up
    </button>
  );
}
```

Because `Counter` subscribes with `useStore('count')`, it updates immediately after `store.set` commits the new value. Reboil persists the state synchronously by default.
