# Reboil Parcel config-registration example

This example uses the optional direct-import workflow generated by `reboil init`.

From the repository root:

```sh
npm install
npm run init-reboil --workspace reboil-parcel-config-app
npm run typecheck --workspace reboil-parcel-config-app
npm run dev --workspace reboil-parcel-config-app
```

`reboil init` creates `reboil.config.ts` and patches `src/main.tsx` so the config runs before the application imports. The app imports `store` from `reboil` and the React hook from `reboil/react`:

```tsx
import { store } from 'reboil'
import { useStore } from 'reboil/react'
```

The workspace enables Parcel package exports so the `reboil/react` subpath resolves through Reboil's export map.
